# Nokta Ayakkabıcılık

Minimal web project scaffold for the `index.html` in this workspace.

Run locally:

- Quick (no install):

```
npx live-server --open=./index.html
```

- With npm (optional):

```
npm init -y
npm install --save-dev live-server
npm start
```

This repository currently contains a single `index.html` file.
